5. LICENSE KEYS, OFFLINE VALIDATION, AND PRIVACY
-------------------------------------------------------------------------------

5.1 Offline by design. License keys are self-contained signed tokens. The
Software validates a key locally on your gateway. It does not contact PA or any
other server to activate, validate, or maintain a license, and it does not
transmit telemetry, usage data, or your content anywhere.

5.2 No revocation. Because validation is entirely offline, an issued key cannot
be revoked or remotely disabled. A key remains valid on its gateway for its term
regardless of any dispute. This is a deliberate trade in favour of gateways on
air-gapped networks.

5.3 Expiry. A key may carry an expiry date. On expiry, the Software continues to
run at unlicensed capacity, as described in section 2.3. It does not stop serving
content, and it does not delete anything you have configured.

5.4 Gateway identifier. The Software generates a random identifier for the
gateway installation on first run and stores it locally. It contains no personal
information and is used solely to bind a key to an installation. You provide it
to PA when ordering.
